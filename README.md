# GWYF Slot Customizer
Customize the slot machine symbols in ```Gamble With Your Friends``` using your own images.

---

## Features
- Replace all 4 slot machine symbols
- Supports custom PNG images
- Simple file-based customization

---

## Installation
1. Install via **Thunderstore / r2modman**
2. Launch the game once to generate folders
3. Navigate to:

```
BepInEx/plugins/agonyz-GWYFSlotCustomizer/GWYFSlotCustomizer/symbols/
```

---

## Customizing Symbols
Replace the following files with your own images:

```
flower.png   → first symbol  
beetle.png   → second symbol  
ankh.png     → third symbol  
eye.png      → fourth symbol  
```

---

## Image Requirements
For best results:
- Resolution: **256x256**
- Format: **PNG**
- Background: **transparent recommended**
- Centered icon
